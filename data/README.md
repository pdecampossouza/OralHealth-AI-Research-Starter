# Data in this starter kit

This repository embeds **20 adult** and **20 pediatric** images only so the project is immediately executable. These samples are demonstrative, not a substitute for the complete research collections.

- Adult sample: `Pranchetas fotografias - dentição permanente - CPOD treinamento`
- Pediatric sample: `Pranchetas fotografias - dentição decídua - Oclusão treinamento`
- Canonical source repository: https://github.com/pdecampossouza/Pipeline-for-Oral-Health-Images
- Source version used for this starter sample: `e23dcdae657f4f999d2e126cee673ce0b4cc25b7`

Serious experiments should retrieve the complete collection relevant to the research question and record the exact source version and subset used. No clinical labels are inferred by this starter kit. The MIT license applies to software code; sample-image redistribution terms are separate and must be verified before public redistribution.
