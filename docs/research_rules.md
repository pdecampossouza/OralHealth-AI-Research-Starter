# Research rules

## Core principle

**The Starter Kit is infrastructure, not a dissertation solution.**

Students are expected to justify model selection, annotation strategy, experimental design, evaluation metrics, statistical analysis, error analysis, and interpretation.

## Minimum methodological rules

- Split by subject/volunteer, not merely by image.
- Define primary metrics before the final experiment.
- Record random seeds, model versions, configuration files, and source-data versions.
- Never infer clinical labels from filenames or appearance without a verified annotation source.
- Keep exploratory experiments separate from final evaluation.
- Perform error analysis, not only aggregate metric reporting.
- Treat domain-expert validation as evidence with an explicit protocol, not as informal confirmation.
- Report uncertainty and limitations.
