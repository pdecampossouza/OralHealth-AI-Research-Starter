# Experimental design guide

A dissertation experiment should state the research question, target population/image collection, prediction task, unit of analysis, data provenance, subject-level split, baselines, candidate architectures, hyperparameter strategy, metrics, statistical comparison, and error-analysis protocol.

Use the sample dataset only to verify code and workflow. Final experiments should use a justified research dataset retrieved from the canonical source repository or another documented source.

Avoid choosing the final architecture only after inspecting test-set performance. Keep the held-out test set for final evaluation whenever feasible.
