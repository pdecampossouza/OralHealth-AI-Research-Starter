# Original dataset and provenance

The source image/pipeline repository is `Pipeline-for-Oral-Health-Images`, associated with the SBBrasil TrainSheets work. The supplied source snapshot used here corresponds to verified commit `e23dcdae657f4f999d2e126cee673ce0b4cc25b7`.

Observed image collections in the source manifest:

1. Pranchetas fotografias - dentição permanente - CPOD treinamento
2. Pranchetas fotografias - dentição permanente - DAI treinamento
3. Pranchetas fotografias - dentição decídua - Oclusão treinamento
4. Pranchetas fotografias - dentição decídua - ceod treinamento
5. Pranchetas fotografias - traumatismo - treinamento
6. Pranchetas fotografias - PUFA - treinamento

The starter kit selects a small deterministic subset only. Researchers should return to the canonical repository to choose complete collections appropriate to their own research questions.
