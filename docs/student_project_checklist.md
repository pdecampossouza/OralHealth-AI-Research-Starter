# Student project checklist

- [ ] Define one primary research question.
- [ ] Identify source image collections and record provenance/version.
- [ ] Define the unit of analysis.
- [ ] Define subject-level train/validation/test split.
- [ ] Confirm no subject leakage.
- [ ] Define annotation ontology and protocol.
- [ ] Define a simple baseline.
- [ ] Select candidate architectures from literature.
- [ ] Define evaluation metrics before final experiments.
- [ ] Record seeds, configs, model versions, and experiment logs.
- [ ] Perform error analysis.
- [ ] Validate relevant outputs with domain experts using a documented protocol.
- [ ] State limitations and uncertainty.
- [ ] Prepare reproducible code, dissertation, and publication-ready artifacts.
