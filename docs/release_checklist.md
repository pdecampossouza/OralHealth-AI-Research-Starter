# Release checklist

## Required before a public v1.0.0 release

- [ ] Confirm that redistribution of the embedded sample images is permitted under the applicable source terms.
- [ ] Confirm the MIT software-license statement and named software authors/contributors.
- [ ] Obtain supervisor and dental-domain-expert review of the starter wording and research-track guidance.
- [ ] Verify the canonical source repository URL and source commit/tag recorded in sample metadata.
- [ ] Confirm citation metadata in `CITATION.cff` and add a DOI only after one is formally assigned.
- [ ] Enable GitHub **Template repository** for the published starter repository.
- [ ] Decide whether to archive/register a release through Zenodo or another institutional service.
- [ ] Re-run all tests and notebook smoke checks in a fresh environment with package-index access.
- [ ] Verify all 40 sample images decode and metadata contain no subject overlap assumptions or fabricated clinical labels.
- [ ] Check that no local paths, model weights, notebook caches, or student research outputs are committed.

## Development release v0.1.0

The `0.1.0` development artifact is intended for supervisor/domain-expert review. It does not claim a DOI, clinical validation, or public-release status.
