# Getting started

1. Create a Python 3.10+ environment.
2. Run `pip install -r requirements.txt`.
3. Open `notebooks/01_getting_started.ipynb`.
4. Run the adult and pediatric examples without modifying paths.
5. Copy `configs/template_research_project.yaml` when you begin your own project.
6. Place your images under `data/your_research_data/images/` or point the config to an external local directory.

The starter kit is deliberately limited. Its purpose is to provide reproducible infrastructure and examples, not to prescribe a dissertation model.
